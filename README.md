# pravo_prjct

# Игра «Этика и Ложь»

Интерактивная новелла о журналистской этике. Игрок проходит через три
реальных истории о журналистах, чьи громкие репортажи оказались (полностью
или частично) ложью, и на каждом шаге выбирает, доверять ли рассказчику.

## Концепция

Игра построена как серия «кейсов» — коротких историй от первого лица.
Персонаж (журналист) рассказывает свою версию событий, после чего игроку
задаётся вопрос-развилка: поверить рассказчику или усомниться. От выбора
зависит, какой финал кейса увидит игрок, но в любом случае дальше следует
экран-разбор, который показывает, что произошло на самом деле.

В игре три кейса:

1. **Брайан Уильямс** (NBC) — история про вертолёт в Ираке.
2. **Джанет Кук** (Washington Post) — репортаж «Мир Джимми» и Пулитцеровская
   премия за вымышленную историю.
3. **Уолтер Дюранти** (New York Times) — отрицание Голодомора в СССР.

После третьего кейса игрок попадает на экран «Заключение», подводящий итог
всем трём историям и предлагающий начать игру заново.

## Игровые механики

- **Анимация печати текста.** Весь повествовательный текст печатается
  посимвольно (имитация старых текстовых адвенчур/чатов), с мигающим
  курсором `▌`. Клик по тексту во время печати сразу показывает его целиком.
- **Покадровая анимация персонажа.** Пока текст печатается, изображение
  персонажа переключается между двумя кадрами (например, открытый/закрытый
  рот), создавая эффект разговора. После завершения печати анимация
  останавливается.
- **Стрелка «далее».** Появляется и начинает пульсировать только после
  завершения печати текста — сигнал игроку, что можно идти дальше. До этого
  момента переход недоступен (`aria-disabled`).
- **Развилка выбора.** На экране вопроса два варианта ответа ведут на разные
  страницы: «выигрыш» (правильное недоверие) или «проигрыш» (поверил лжи).
- **Разбор кейса.** Независимо от выбора, после короткой реакции персонажа
  игрок попадает на страницу с фактами о том, что произошло в реальности.
- **Сквозной переход между кейсами и финал.** Каждый кейс заканчивается
  кнопкой перехода к следующему, последний — кнопкой «К итогам», а с экрана
  заключения можно вернуться к самому началу игры.

## Структура проекта

Каждый экран — отдельная HTML-страница (без SPA-роутинга), переходы между
ними — обычные ссылки `<a href="...">`. Это сделано для простоты: каждую
страницу можно открыть и протестировать по отдельности.

```
index.html              — Кейс 1, экран 1 (рассказ)
question.html           — Кейс 1, экран вопроса
win.html / lose.html    — Кейс 1, исходы
result.html             — Кейс 1, разбор

case2.html               — Кейс 2, экран 1
case2_question.html
case2_win.html / case2_lose.html
case2_result.html

case3.html               — Кейс 3, экран 1
case3_question.html
case3_win.html / case3_lose.html
case3_result.html

conclusion.html          — финальный экран

stylesheets/
  style.css              — общий каркас и стили (база — оформление кейса 1)
  fonts.css              — подключение шрифта Anonymous Pro
  content_case_2.css     — переопределения цветов/стилей для кейса 2
  content_case_3.css     — переопределения цветов/стилей для кейса 3
  content_conclusion.css — стили финального экрана

javascripts/
  java-script.js          — общая логика (печать текста + кадровая анимация)

images/                   — все изображения (персонажи, фоны, иконки)
```

## Технические детали

- **Вёрстка на `vw`.** Все размеры посчитаны от ширины экрана 1440px и
  переведены в `vw` (`значение_px / 1440 * 100`), поэтому макет масштабируется
  целиком при изменении ширины окна. Высота главного контейнера `.case_1`
  задаёт общий масштаб экрана.
- **Темизация через классы и CSS-переменные не используются** — вместо
  этого у каждого кейса есть свой класс (`.case_2`, `.case_3`) на корневой
  секции и отдельный CSS-файл с переопределениями (цвет полосы сверху,
  угловых меток, рамки экрана, фона карточки вопроса и т.д.). Базовые стили
  кейса 1 лежат в `style.css` и переопределяются только там, где нужно.
- **Общий JS-движок.** `java-script.js` содержит одну функцию
  `setupTypingScreen()`, которая:
  - находит элемент текста по `id`;
  - если у элемента задан атрибут `data-fulltext`, печатает именно этот
    текст (так в `style.css`/JS не нужно хардкодить тексты каждого кейса —
    текст лежит прямо в HTML конкретной страницы);
  - запускает покадровую анимацию персонажа (`.frame-b` toggle между двумя
    `<img>`), пока идёт печать;
  - показывает стрелку «далее» (`.next-arrow-hit`) только после завершения
    печати.
    Функция вызывается на каждой странице с разными `id`/селекторами; если
    нужного элемента на странице нет — вызов просто ничего не делает
    (`if (!textEl) return`), поэтому один файл скрипта подходит для всех
    страниц.
- **Шрифт.** Везде используется моноширинный `Anonymous Pro` (с фолбэком на
  `Courier New`) — подчёркивает стилистику «текстового» репортажа/чата.
